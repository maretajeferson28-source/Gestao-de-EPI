# Gestão de EPI

Sistema web de gestão de EPI conectado ao Supabase e publicado no Netlify.

## Estrutura
- `index.html`
- `css/style.css`
- `js/config.js`
- `js/app.js`
- `_headers`

## Backend
Supabase: projeto `Gestao-EPI`.

O frontend usa somente a chave publishable do Supabase. Segredos e chaves service role não devem ser versionados.

## Deploy
Este repositório será conectado ao Netlify para deploy automático.

Versão inicial importada: V4.4 — tabela de movimentações com colunas estáveis e coluna de ação fixa.
